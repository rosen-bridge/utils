## Table of contents

## Introduction

A utility package for services that uses @rosen-bridge/service-manager containing tools such as draw the dependency graph of services

## Installation

npm:

```sh
npm i @rosen-bridge/service-manager-cli
```

yarn:

```sh
yarn add @rosen-bridge/service-manager-cli
```
