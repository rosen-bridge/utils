## Introduction

A Typescript package for encoding and decoding of Bitcoin (Runes) addresses in Rosen bridge

## Installation

npm:

```sh
npm i @rosen-bridge/address-codec-bitcoin-runes
```

yarn:

```sh
yarn add @rosen-bridge/address-codec-bitcoin-runes
```
